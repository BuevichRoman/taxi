# Агентам

Работа в этом репозитории — дописывать сценарии в браузере.
**Полная вводная: [`AI_TESTING.md`](AI_TESTING.md)** — прочитай её перед тем,
как что-то менять.

Кратко, чтобы не начать не с того:

- сценарии живут в `e2e/specs/*.spec.ts`, проверка одна — `npm run e2e`;
- вне `e2e/**` менять ничего не нужно. Падение из-за приложения — находка,
  её описывают, а не лечат правкой `src/**`;
- время двигает мок (`advanceClock`), а не ожидание; приложение и API
  отвечают с одного адреса — иначе часы приложения встанут.
